# Q1 Experiment Configuration Files

This directory contains configuration files for the SS-NFPSO Q1 experiment pipeline.

## Files

- `datasets.json`: real, synthetic, and planned public datasets.
- `models.json`: forecasting baselines, legacy NFPSO, and projected-constricted NFPSO settings.
- `q1_minimal_experiments.json`: small experiment package for testing the pipeline.
- `q1_full_experiments.json`: larger experiment package intended for the final manuscript.

## Important rules

- Do not commit private raw data.
- Do not commit experiment outputs if they contain real values or predictions.
- The Yemeni tax-revenue dataset is referenced as a local authorized file only.
- Synthetic datasets should be generated by code.
- Public datasets should be added only when redistribution is allowed, or replaced by preprocessing/download scripts.

## Recommended execution order

1. Run the minimal configuration first.
2. Validate outputs, tables, and figures.
3. Only then run the full configuration.
